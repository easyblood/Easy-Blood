EASY BLOOD — COMPLETE LAB MANAGEMENT BACKEND

1. Install Node.js 20+ on a computer/server.
2. Open terminal in the server folder.
3. Run: npm install
4. Copy .env.example to .env and set JWT_SECRET + MANAGEMENT_PASSWORD.
5. Run: npm start
6. Open: http://localhost:3000

Default management login for first setup if MANAGEMENT_PASSWORD is not set:
Login ID: easyblood
Password: easyblood123
CHANGE IT before real patient data.

Management can create patient reports, enter test results, search reports and generate a PDF containing the Easy Blood name, report ID and QR verification link.
Patients do NOT receive the management login. They open only the verification link/QR page.

Existing website files are preserved. The new lab-management.html is the working management screen.
